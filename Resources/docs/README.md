# FitOnus project handbook

FitOnus is a mobile fitness and nutrition application with a backend API, an admin dashboard, and an AI coach.

Start with the [coding agent guide](../../AGENTS.md) and [documentation index](INDEX.md). The current application uses an Express/PostgreSQL backend with Gemini, a React Native/Expo mobile app, and a Next.js admin app. Component package manifests define exact dependency versions.

The numbered `01`–`27` documents capture product requirements and the original design plan. Some proposed technologies and integrations are not implemented. Read them for feature intent, then consult component guides and source code for current behavior.

- [Agent rules](AGENT_RULES.md)
- [Original development plan](DEVELOPMENT_WORKFLOW.md)
- [Architecture decisions](ARCHITECTURE_DECISIONS.md)
- [Changelog](CHANGELOG.md)

Keep durable project context in these guides and component documentation. Historical task reports and UI review exports were removed from the working tree; committed versions remain available in Git history.
